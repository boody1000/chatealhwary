الخطأ الظاهر في الصورة (`401 Unauthorized`) سببه أن مفتاح الـ API الخاص بـ Daily.co غير صحيح أو منتهي الصلاحية، ولأن إنشاء الغرف برمجياً من المتصفح تطلب مفتاحاً سرياً (يؤدي لرفضه أمنياً)، سنعود للطريقة الأبسط والأضمن التي استخدمناها في البداية (إصدار تليجرام/الروابط الثابتة) بدون الحاجة لطلبات `POST` معقدة تتسبب في هذا الخطأ. إليك الكود الكامل لملف **العميل** وملف **الموظف** ليعودا للتصميم والعمل بالطريقة البسيطة والصحيحة: ### 1. كود ملف العميل (`client.html`) ```html تواصل مع الدعم - شركة الهواري

محادثة خدمة العملاء

المكالمة الصوتية جارية...
00:00
``` --- ### 2. كود ملف الموظف (`employee.html`) ```html لوحة تحكم الموظف - شركة الهواري

إدارة المحادثات

اختر عميلاً لبدء المحادثة

جاري المكالمة الصوتية...
00:00
``` قم بنسخ هذه الأكواد وتجربتها، وستعمل المكالمات مباشرة وبدون مشاكل الـ API الخارجية.
